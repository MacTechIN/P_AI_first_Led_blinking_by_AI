# Chapter 1 시안

`../ppt-outline.md` 의 마스터 사양을 실제 슬라이드로 구현한 것.
참조 교재 `31.AX컨설팅방법론_통합교재` 의 포맷을 따른다.

| 파일 | 내용 |
|---|---|
| `ch1-draft.pptx` | 6슬라이드 시안 |
| `build.js` | 생성 스크립트 (pptxgenjs) |
| `cover_bg.png` | 표지 배경 (PIL 생성, 2666×1500) |

## 포함된 마스터 4종

| 슬라이드 | 마스터 | 내용 |
|---|---|---|
| 1 | **M1 표지** | 그라데이션 + 네트워크 그래픽 + 5단계 곡선 |
| 2 | **M2 간지** | 좌측 회색 블록 + 대형 숫자 |
| 3 | **M3 개념** | `1-1. 화면 안의 AI` — 회색 헤더바 + 번호 박스 3열 |
| 4 | **M3 비교** | `1-2. 화면 밖으로 나오면` — 2열 비교표 + 검은 배너 |
| 5 | **M4 산출물** | 하드웨어 적합성 판정 (실측) |
| 6 | **M4 실패 사례** | 7B 사망 — 3단계 진행 + 원인 카드 |

M5 워크시트는 Chapter 5 에서 쓰므로 이 시안에는 없다.

## 재생성

```bash
cd <작업 디렉터리>
npm install pptxgenjs
python3 ...   # cover_bg.png 생성 (build 주석 참조)
NODE_PATH=$PWD/node_modules node build.js
```

## 색상

| 용도 | 값 |
|---|---|
| 표지 | `162E68` → `265CB4` 그라데이션 · 강조 `E8A355` |
| 간지 | `8A8A8A` |
| 개념 (M3) | 흑백 · 헤더바 `7F7F7F` |
| Phase 1 관측 | `0F7B8A` (청록) |
| 실패 사례 배지 | `B03A2E` |

Phase 2~5 색은 `../ppt-outline.md` 1.2 절 참조.

## 서체

`Malgun Gothic` — 한국어 Office 표준. 미리보기 렌더링은 Noto Sans CJK KR 로
대체되므로 **자간이 약간 다를 수 있다.** 실제 PowerPoint 에서 다시 확인할 것.

## 알려진 제약

- `pptxgenjs` 는 그라데이션 채우기를 지원하지 않아 표지 배경을 이미지로 넣었다.
  색을 바꾸려면 `cover_bg.png` 를 다시 생성해야 한다.
- 네트워크 그래픽은 난수 시드 `7` 로 고정했다. 같은 그림을 다시 얻으려면 유지할 것.
