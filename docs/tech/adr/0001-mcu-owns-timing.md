# ADR-0001 — 타이밍은 MCU가 소유한다

상태: 채택   날짜: 2026-09-16   슬라이스: VS-0

## 배경
호스트(Jetson)가 LED 점멸을 만드는 방법은 두 가지다. 호스트가 매 전환마다
ON/OFF를 보내거나, MCU에 주기를 알려주고 MCU가 스스로 돌리거나.

## 결정
**MCU가 타이밍을 소유한다.** 호스트는 `INT 200` 같은 의도만 전송한다.

## 근거
호스트 주도 방식은 USB CDC 왕복 지연과 리눅스 스케줄러 지터에 노출된다.
주기가 100ms 수준으로 내려가면 눈에 보이게 불규칙해진다.
아두이노의 `millis()` 루프는 이 두 요인과 무관하다.

## 대안과 기각 사유
- **호스트 주도 토글**: 지연·지터에 취약. 기각.
  단 `--pattern sos` 처럼 의도적으로 호스트가 타이밍을 쥐는 경우는 예외로 허용한다.
- **RTOS 도입**: 현 요구에 과하다. 기각.

## 결과
- 이 원칙은 LED를 넘어 전체 아키텍처로 확장된다:
  **느린 정책 루프(AI)와 빠른 제어 루프(MCU)의 분리.**
- VLM 추론이 초 단위여도 액추에이터 거동은 매끄럽게 유지된다.
- MCU가 상태를 소유하므로 호스트 재연결 시 상태 동기화 설계가 필요하다.
  포트 열기가 DTR로 Uno를 리셋시켜 설정이 기본값으로 돌아가는 부작용을
  VS-4에서 다룬다.
