# ADR-0004 — 인지 계층을 인터페이스로 추상화한다

상태: 채택   날짜: 2026-09-16   슬라이스: VS-1 (µ1.4)

## 배경
카메라 확보가 임계 경로를 막고 있었다. IMX708 이 JetPack 미지원으로 판명되어
교체가 필요했고, 그동안 VS-2 이후를 전혀 시작할 수 없는 상태였다.
또한 USB 웹캠으로 시작해 CSI 로 옮길 가능성이 높아, 교체가 상위 계층에
전파되지 않아야 했다.

## 결정
상위 계층은 `FrameSource` 인터페이스만 본다. 구현체는 소스 지정 문자열로 고른다.

    open_source("synthetic")   # 카메라 없이 개발
    open_source("v4l2:0")      # 실물 카메라
    open_source("files:...")   # 골든셋 재생

관측 자료형은 이미지 단독이 아니라 `Observation{image, sensors, seq, timestamp}` 다.

## 근거
- **임계 경로 차단.** 합성 소스가 있으면 카메라 없이 VS-2~VS-4 를 개발할 수 있다.
  실제로 µ1.4 의 22개 시험이 카메라 없는 상태에서 전부 통과한다.
- **교체 비용 0.** USB ↔ CSI 전환이 소스 지정 한 줄이다.
- **센서 확장 대비.** VS-5(µ5.3)에서 조도·소리·연기가 들어올 때 포맷을
  재설계하지 않도록 `sensors` 슬롯을 지금 만든다. 나중에 추가하면
  모든 소비자를 고쳐야 한다.

## 부수 결정 — 색 공간은 RGB
cv2 는 BGR 을 주지만 `Observation.image` 는 항상 **RGB** 다. 변환은
`V4L2Source` 경계에서 한 번만 일어난다.
근거: VLM 과 PIL 이 RGB 를 기대한다. 소비자마다 "이게 BGR 인가" 를 기억해야 하는
규칙을 남기면 반드시 어딘가에서 틀린다.

## 대안과 기각 사유
- **cv2.VideoCapture 직접 사용**: 카메라 없이 테스트 불가. 교체가 전파된다. 기각.
- **이미지만 넘기고 센서는 나중에**: VS-5 에서 전 소비자 수정 필요. 기각.
- **BGR 유지 (cv2 관행)**: 변환을 소비자에게 미루는 것이며, VLM 입력에서
  색이 뒤집히는 버그는 조용히 발생해 발견이 늦다. 기각.

## 결과
- 합성 소스의 `patch()` / `moving_patch()` 가 VS-2 의 "동일 색 표시" 와
  "방향 표시" 판단 로직 개발을 카메라 없이 가능하게 한다.
- `check_health=False` 로 원시 디버깅 경로를 남겨둔다 (ADR-0005 와 병행).
