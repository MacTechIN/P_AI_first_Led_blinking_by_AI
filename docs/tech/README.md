# 기술 기록 (Technical Records)

오케스트레이션 계층(L4)의 구성요소. 프로젝트 구현에 필요한 기술 내용을
기록하고 보관한다. 상세 원칙은 `../development_plan.md` 3절 참조.

```
adr/     아키텍처 결정 기록 — 되돌리기 어려운 결정마다 1파일
notes/   조사 · 실험 노트 — 시도한 것과 결과, 실패 포함
refs/    외부 자료 요약 — URL + 핵심 내용 (오프라인 참조용)
```

## 기록 원칙

- **실패를 남긴다.** 무엇을 시도했고 왜 안 됐는지가 더 비싼 정보다.
- **소거된 변수를 명시한다.** 다음 사람이 같은 실험을 반복하지 않도록.
- **수치를 남긴다.** "느리다"가 아니라 "종단 지연 2.4초".
- **재현 명령을 남긴다.** 결론뿐 아니라 그것을 얻은 명령을 함께.
