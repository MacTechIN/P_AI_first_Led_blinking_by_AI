# 예제 1 측정 — 공간 판단에서 규칙 vs VLM (2026-09-18)

"AI 를 언제 쓰고 언제 쓰지 않을지" 를 가르치려면 **AI 가 지는 사례**가 필요하다.
방향 판단이 그 사례다.

## 방법

정답이 확실한 합성 이미지를 쓴다. 색 사각형을 **정확히 아는 위치**에 그려 넣으므로
채점에 논란의 여지가 없다. 좌·중·우 세 구역으로 나누고, 화면 가로 0.10~0.90 을
9등분해 물었다.

양쪽에 같은 이미지를 준다. 규칙은 `extract().centroid_x`, VLM 은
`llama-server` 의 Qwen2.5-VL-3B.

```bash
./host/measure_direction.py --positions 9
```

## 결과

| | 정확도 | 평균 지연 |
|---|---|---|
| **규칙 기반** | **9 / 9** | **7.4 ms** |
| VLM (3B) | 3 / 9 | 2472 ms |

규칙이 **완벽하고 330배 빠르다.**

### VLM 의 실패는 "부정확" 이 아니라 "퇴화" 다

| 정답 x | 정답 | VLM |
|---|---|---|
| 0.10 | left | left |
| 0.30 | left | left |
| 0.50 | centre | **left** |
| 0.70 | right | **left** |
| 0.90 | right | **left** |

**9개 전부 `left` 로 답했다.** 맞은 3개는 우연히 왼쪽이었을 뿐이다.
모델이 위치를 조금 틀리는 것이 아니라, **위치를 보고 있지 않다.**

## 이미지를 키우면 나아지는가 — 아니다

llama.cpp 가 경고한다:

```
Qwen-VL models require at minimum 1024 image tokens to function correctly
on grounding task
```

그래서 크기를 올려 봤다.

| 크기 | 정확도 | 지연 | 답변 |
|---|---|---|---|
| 768×432 | 2/5 | 2323 ms | 전부 left |
| 1024×576 | 3/5 | 5572 ms | left ×4, right ×1 |
| 1280×720 | 3/5 | 8101 ms | left ×4, right ×1 |

**하나 더 맞히는 대가로 지연이 3.5배**가 된다. 그리고 여전히 퇴화 답변이다.
이 모델은 우리가 감당할 수 있는 어떤 크기에서도 공간 그라운딩을 하지 못한다.

메모리 예산상 7B 는 쓸 수 없다(`vlm-on-orin-nano.md`). 즉 **이 기계에서 방향 판단은
규칙으로 하는 것이 유일한 실용적 선택**이다.

## 가르칠 것

> **AI 가 항상 낫지 않다.** 색 판별에서는 VLM 이 잘했고, 방향 판단에서는
> 규칙이 완승했다. 차이는 문제의 성질에 있다 — 색은 의미 해석이고,
> 위치는 산술이다. **산술을 모델에게 시키지 마라.**

그리고 실패의 **모양**을 보는 법도 가르친다. 3/9 만 보면 "좀 부정확하다" 로
읽힌다. 답변 목록을 보면 **아예 보지 않고 있다**는 것이 드러난다.
정확도 숫자 하나로 모델을 판단하면 이 차이를 놓친다.

## 측정 중에 찾은 버그 두 개

### 1. `centroid_x` 가 ROI 상대 좌표였다 (실제 버그, 수정됨)

ROI 는 화면 가운데 60%(0.2~0.8)인데, 그 안에서 잰 중심을 **프레임 좌표로 환산하지
않고** 내보내고 있었다. 색 판별에서는 쓰이지 않던 값이라 드러나지 않다가,
위치를 쓰는 순간 9개 중 4개가 틀렸다.

```python
in_roi = xs.mean() / obj.shape[1]
centroid_x = x0 + in_roi * (x1 - x0)      # 수정: 프레임 기준으로 환산
```

수정 후 규칙은 5/9 → **9/9**. 시험으로 고정했다
(`test_centroid_is_frame_relative_not_roi_relative`).

**교훈:** 어떤 목적으로 쓰이지 않는 필드는 틀려도 조용하다.

### 2. `max_tokens` 가 JSON 을 잘랐다

처음에 `max_tokens=24` 로 두었더니 9개 전부 실패했다.

```
JSON 이 아니다: '{\n  "action": "on",\n  "colour": "blue",\n  "reason": "'
```

**스키마를 강제해도 토큰이 모자라면 JSON 이 완성되지 않는다.** 잘린 JSON 은
유효하지 않은 JSON 이고, 증상은 "모델이 이상한 답을 한다" 로 보인다.

**교훈:** 구조 강제는 문법을 보장하지, 완결을 보장하지 않는다.

## 재현

```bash
./host/measure_direction.py --skip-vlm      # 규칙만, 하드웨어 불필요
./host/measure_direction.py --positions 9   # 서버 필요
```
